# FrostBanner GTM template — правила работы для Claude Code

## О проекте
- Шаблон FrostBanner для Google Tag Manager (Community Template Gallery). Главный файл — `template.tpl` (экспорт из редактора шаблонов GTM): разделы `___INFO___`, `___TEMPLATE_PARAMETERS___`, `___SANDBOXED_JS_FOR_WEB_TEMPLATE___`, `___WEB_PERMISSIONS___`, `___TESTS___`, `___NOTES___`.
- Код шаблона работает в **песочнице GTM** (sandboxed JavaScript): только API через `require(...)`, каждое действие должно быть разрешено в `___WEB_PERMISSIONS___`. Обычный JS браузера (`window`, `document`, `setTimeout`, `addEventListener`) недоступен.
- Шаблон загружает виджет с продакшена `https://app.frostbanner.com/v1/fb.js`. Исходник виджета: `../frostbanner-repo/src/fb.js` (только читать, не менять). Публичный API виджета: `FrostBanner.getConsent()`, `FrostBanner.on(event, fn)`; события `change` ({ choices, source }), `shown`, `consentmode`. С `frostBannerConfig.gtm = true` виджет **не** шлёт свои `gtag('consent', …)` — согласие в Google передаёт только шаблон.
- Репозиторий **публичный** (лицензия Apache 2.0). Галерея берёт шаблон с коммита, указанного в `metadata.yaml` (`sha`).

## Общение
- Отвечай на русском, коротко, по пунктам. Английские термины при первом упоминании поясняй по-русски. Риски — прямо.

## Git — строгие правила
- **Никогда не делай `git push` без явного разрешения** в текущем сообщении. Никогда `push --all`, `--mirror`, `--force`.
- Одна задача — один коммит, сообщение на английском.
- **`metadata.yaml` (sha) не менять**, пока владелец не проверил шаблон в предпросмотре GTM и не сказал обновить.
- Не коммить папку `reports/` (она в `.gitignore`), ключи, токены.
- Не удаляй файлы и ветки без подтверждения.
- Работай только в этой папке; `../frostbanner-repo` — только читать.

## Изменения в template.tpl
- Каждое изменение кода — с тестом в `___TESTS___` (формат тестов редактора GTM: `mock`, `runCode`, `assertApi`, `assertThat`).
- Встроенные тесты запускаются **только в интерфейсе GTM**. Ты их запустить не можешь — проверяй логику вручную по коду и честно пиши в отчёте, что тесты не запускались.
- Разрешения — минимально необходимые. Если API больше не используется, убери и его разрешение.
- Файл должен оставаться валидным для импорта в редактор шаблонов GTM: не ломай разделители разделов и JSON в `___TEMPLATE_PARAMETERS___` / `___WEB_PERMISSIONS___`.

## Как завершать задачу
1. Сделай изменения.
2. **Независимая проверка:** запусти отдельного агента-проверяющего, который не видел, как писался код. Он сверяет шаблон с `../frostbanner-repo/src/fb.js`, проверяет логику согласия (GDPR: до выбора всё запрещено), разрешения, валидность формата и тесты, и пишет вердикт. Найденное исправь до слова «готово».
3. Закоммить (без push).
4. Отчёт в `reports/ГГГГ-ММ-ДД-кратко.md`: что сделал, коммиты, вердикт проверяющего, что проверить в предпросмотре GTM по шагам, риски.
5. В чате — короткое резюме и путь к отчёту.
